## 2. 完成內容

**一、怪物補齊**
- M002 苔角獸、M003 雲絨鳥：依 Claude A 存檔的原始模型製作 HQ／Lite＋7 組動畫（Idle、Move、Run、Attack、Hurt、Death、Respawn），造型沒有改；專案內沒有這兩隻的設定圖，尺寸依地圖文件。
- 七隻怪物統一規格表（尺寸、骨架、碰撞、動畫名稱、命中時間、死亡重生介面）與完整資產清單：見交付文件。
- 展示頁實戰：M002～M007 六隻骨骼動畫怪物（M001 是遊戲內已驗收的程式動畫模型，不在展示頁）。

**二、角色戰鬥動畫 V2**（C1.0-B5b 男女；沒有用 Tripo 組裝角色，外觀沒有改）
- 六個技能改成關鍵姿勢動畫：蓄勢 → 出招 → 命中 → 收招；腰先轉、肩晚 2 格、頭與左手晚 3～4 格。
- 重心移到支撐腳並側傾；踏步抬腳走弧線，著地後固定不滑（每 1/120 秒漂移 < 2.4 mm；旋風斬原地轉身例外）。
- 三連斬：前踏橫斬 → 交叉步上撩 → 深蹲蓄勢小跳迴旋斬＋劍氣；跳斬：深蹲擺臂起跳、空中舉劍、下劈落地；
  旋風斬：反向蓄勢、兩圈、煞車過頭再收；魔法彈：後撤引杖、聚氣、前踏推杖；星隕：舉杖向天、拉回、指向目標、受衝擊後仰；
  蓄力：深弓步蓄力（顫動）→ 再沉 → 爆發突進上撩。

**三、特效 V2**
- 多層：劍氣（主色＋白色刀鋒＋柔光）、魔法陣（主陣＋反轉內圈＋符文環＋上升光點＋收尾脈衝）、蓄力（光暈＋內聚粒子＋收束環＋釋放閃光）、
  魔法彈（核心＋旋轉光星＋緞帶尾跡＋粒子尾巴）、命中（閃光＋擴散環＋火花）、地面衝擊（衝擊環＋立牆＋碎石＋地裂紋）、星光碎片、光柱。
- 暴擊：金色閃光＋碎片＋小震波＋畫面閃光＋暴擊數字（震動、旋轉、放大回彈）。
- 傷害數字 V2：彈出回彈、拋物線、疊字不重疊。怪物受擊：閃白＋Hurt＋擊退（地形擋住）＋頓幀。
- 白天草地環境：彩色層改一般混合＋飽和色，白天也看得清楚（截圖與影片已確認）。

**四、六大職業共用架構**：`core/classes.ts`（動畫分類、特效家族、展示組合）＋展示頁「職業特效」按鈕＋新特效鍵值（光盾、盾擊、突刺、鍛造火花、治療光環、增益環繞、道具彩紙）。

**五、手機效能與多人**：其他玩家合併模型（26→2 個 draw call）、武器合併、材質共用、其他玩家特效簡化、物件池、粒子／距離／份額限制。

**六、遊戲規則**：攻速上限 160、沒有跳躍鍵（跳躍只在技能內）、技能不穿越不可通行地形、動畫／特效／傷害同步、Lv1～4 被動、Lv5 以上主動、Lv1～10 無屬性、多人由伺服器決定傷害（介面與文件）。

# 3D 畫面渲染升級 — 第一階段（feature/render-upgrade）

## 畫質模式（src/render/quality.ts）

| 項目 | 高 | 中 | 低 |
|---|---|---|---|
| 解析度上限 | 2x | 1.5x | 1.25x |
| 後製管線 | 開（HDR） | 開（HDR） | 關 |
| 抗鋸齒（只用一種） | MSAA 4x（後製內） | FXAA | 畫布內建 MSAA |
| 選擇性 Bloom（星星、魔法、特殊材質） | 開（0.5 解析度） | 開（0.25 解析度） | 關 |
| 陰影 | 柔和接觸陰影 PCSS 2048 | PCF 1024 | PCF 512 |
| 色調映射＋曝光 | 開 | 開 | 開（在材質內處理，成本極低） |
| HDR 環境貼圖 | 允許 | 允許 | 不載入 |

- 預設：手機（觸控為主）= 中、電腦 = 高、記憶體 ≤ 2GB = 低
- 網址 `?quality=high|medium|low` 可指定；畫面右上「畫質」按鈕可切換（會記住並重新載入）
- 動態解析度沿用原機制：連續 2 秒低於 40 FPS 降一級，最低 1x

## 主要元件（src/render/）

- `RenderQuality.ts`：建立引擎（依畫質決定抗鋸齒）、色調映射（KHR PBR Neutral）、曝光、後製管線、選擇性 Bloom（GlowLayer，只有註冊的物件發光）、陰影、3D 漸層天空、HDR 環境貼圖載入（預留）
- `pbr.ts`：PBR 材質工具與預設（布料、果凍、發光）；**現有材質未轉換**
- `PerfOverlay.ts`：FPS、Draw Calls、Active Meshes、解析度、畫質切換、動態解析度

## 為什麼 Bloom 用「選擇性」

全畫面 Bloom 會讓明亮的天空與草地整片發白；改用只對星星、光環等註冊物件發光的方式，
符合「主要作用於發光星星、魔法效果及特殊材質」。

## 天空

後製管線需要不透明畫面，原本的 CSS 背景天空改為 3D 漸層天空球（顏色依星露啵啵設定圖）。

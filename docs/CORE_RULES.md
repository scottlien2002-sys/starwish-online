# 星願物語 Starwish Online — 核心設定（不可擅自更改）

修改任何一條都必須先經企劃確認，並同步更新 `src/core/rules.ts`、`src/core/canon.ts` 與單元測試。

## 遊戲類型
- 經典 3D Q版 MMORPG，手動打怪與升級（不做自動戰鬥）
- 第一版為單機可玩原型，架構保留多人連線擴充

## 職業（正式名稱）
初心者、劍士、法師、祭司、小丑、弓箭手、騎士
- 第一階段先製作：初心者、劍士

## 怪物（正式名稱）
星露啵啵、苔角獸、焰尾狐

## 數值與裝備
- 等級：第一版 Lv.1～20
- 角色攻擊速度最高 **160**
- 裝備每 **5 等一階**；第一版提供 Lv.5、10、15、20 裝備
- 裝備**不設稀有度**
- 每件裝備只能鑑定出**一條**附加屬性

### 武器鑑定詞條
| 詞條 | 可能數值 |
|---|---|
| 攻速 | +4 / +6 / +8 / +10 |
| 攻擊力 | +10% / +12% / +15% |
| 命中率 | +6% / +8% / +10% |
| 暴擊率 | +10% / +20% |

### 防具鑑定詞條
| 詞條 | 可能數值 |
|---|---|
| 防禦力 | +5% / +10% / +15% / +20% |
| 生命值 | +50 / +100 / +150 / +200 |
| 格擋率 | +2% / +4% / +6% / +8% |
| 攻速 | +4 / +6 / +8 / +10 |

### 強化
- +1～+10，採用已確認的**平衡型**強化制度
- 成功率、材料、失敗處理：**待企劃提供**（`src/config/enhance.json` 目前為 null）

### 資料儲存
- 鑑定機率、強化成功率、材料數值放在獨立設定檔（`src/config/*.json`）
- 裝備的鑑定紀錄、強化紀錄、掉落紀錄必須**分開儲存**

## 美術方向
- 3.2 頭身 Q版角色、日系動畫渲染、明亮童話奇幻場景、柔和光影
- 角色、怪物、場景風格統一
- 模型格式優先 GLB / glTF
- 程式化暫代模型（名稱以 `PH_` 開頭）**不是**正式美術

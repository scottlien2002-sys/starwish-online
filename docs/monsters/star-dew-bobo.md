# 星露啵啵 Star Slime — 3D 實作說明

美術參考：使用者提供的「怪物設定圖 01：星露啵啵」（唯一參考）。
設定：新手區常見的魔法生物，由星露能量聚集而成，外型圓潤可愛，性格溫和，受到驚嚇時會彈跳逃跑。

## 架構（模型與動畫分離）

```
MonsterAnimator（動畫控制器，純邏輯，不依賴 Babylon）
 ├─ MonsterStateMachine   狀態與衝突規則
 ├─ AnimProfile           六種動作曲線 + 特效時間軸（profile.ts / bobo-poses.ts）
 └─ MonsterView 介面      ← StarDewBoboModel（程式化暫代模型）
                           ← 未來：GLB 模型只要實作同一介面即可替換
```

- `MonsterPose`：每幀輸出的姿勢資料（位移、伸縮、前傾、透明度、星光、觸角、翅膀、表情、光環）
- `MonsterEffect`：特效事件（attackImpact、deathBurst、respawnStart、respawnPop）
- 換 GLB 時有兩種做法：(1) 用骨架/節點套用 MonsterPose；(2) 依 state 播放 GLB 內建動畫，特效事件照用

## 六種動作

| 動作 | 時長 | 內容 |
|---|---|---|
| Idle 待機 | 2.4 秒循環 | 呼吸伸縮 ±4.5%（體積守恆）、觸角與翅膀輕擺、星光呼吸 |
| Move 移動 | 0.62 秒一跳 | 起跳拉長、空中最高 0.42、落地擠壓 30% |
| Attack 攻擊 | 0.8 秒 | 蓄力後退 → 衝撞前進 1.1 → 撞擊壓扁（0.38 秒觸發撞擊事件）→ 彈回原位；生氣表情 |
| Hit 受傷 | 0.4 秒 | 震動遞減、閃白、> < 表情 |
| Death 死亡 | 1.5 秒 | 受擊壓縮 → 攤平成水窪並淡出，星光粒子爆散 |
| Respawn 重生 | 1.6 秒 | 地面光環展開、星光上升 → 星星先出現 → 身體回彈凝聚 → 輕微晃動定型 |

## 衝突規則（MonsterStateMachine）

| 目前狀態 \ 請求 | 待機/移動 | 攻擊 | 受傷 | 死亡 | 重生 |
|---|---|---|---|---|---|
| 待機/移動 | 立即切換 | ✓ | ✓ | ✓ | ✗ |
| 攻擊 | 排隊（攻擊後生效） | ✗ | 疊加閃白，不中斷攻擊 | ✓ 中斷 | ✗ |
| 受傷 | 排隊 | ✗ | 重新計時 | ✓ 中斷 | ✗ |
| 死亡中 | ✗ | ✗ | ✗ | ✗ | ✗（等播完） |
| 已死亡 | ✗ | ✗ | ✗ | ✗ | ✓ |
| 重生中 | 排隊 | ✗ | ✗（無敵） | ✗ | ✗ |

## V1.1 修正（2026-11-15，依 iPhone Safari 實測回饋）

- 移動動畫：跳躍高度 0.42→0.3、空中拉長 14%→6%、落地壓扁 30%→10%，全程寬高變形比 ≤ 1.2（有單元測試）
- 五官反向補償：眼睛、腮紅、嘴巴、胸前星星跟著身體表面移動，但只承受 20% 的伸縮變形
- 測試場景移動時以 3/4 側面朝向鏡頭（原本完全面向前進方向，臉常轉到側面）
- 中央高光：反光強度 0.9→0.3、範圍放寬（power 64→18），不再出現刺眼白點
- 果凍材質：中心約 30% 不透明、邊緣 100%，加上柔和邊緣反光
- 體內星空：貼圖改深藍底（加法混色下星點才清楚）、星點與閃光加大加多；新增跟著身體移動的體內星光粒子
- 翅膀：改為根部圓、尖端收細微下垂的水滴鰭，雙層半透明，邊緣較實、中間較透
- 動畫狀態機與其他五種動作未修改

## V1.2 修正（2026-11-15，依 iPhone Safari 實機影片回饋）

- 移動：前傾 0.08→0.05、觸角擺動 0.35→0.2；測試場景改為鏡頭前左右來回（不再繞圈旋轉），只在折返時平滑轉身
- 攻擊三階段（0.9 秒）：① 蓄力 0~0.32 秒（後退、壓低、發抖）② 衝撞 0.32~0.42 秒（向前拉長衝出）＋ 撞擊瞬間前方壓扁 ③ 回彈 0.5~0.9 秒（往後小跳、落地輕壓）；撞擊事件改在 0.42 秒
- 新增前後方向伸縮 stretchZ（衝撞拉長、撞擊壓扁），體積守恆
- 頂部過曝：受光顏色、反光強度降低，邊緣反光只出現在輪廓；V1.0/V1.1 的內層用加法混色是發白主因，已改為一般混色
- 立體星空：內層星空（一般混色）＋ 第二層星點殼（加法混色、反向流動）＋ 體內星光粒子，三層產生前後視差
- iPhone 效能：身體網格面數降低、光暈運算解析度 0.5→0.3、陰影貼圖 1024→512、低於 40 FPS 自動降解析度
- 待機、受傷、死亡、重生的動作曲線與所有狀態切換規則未修改

## 與設定圖的差異（目前程式化版本無法完全還原的部分）

正式設定沒有被更改；以下是**暫代模型的還原落差**，之後以 GLB 正式模型補足：

1. **身體材質**：用半透明材質 + 邊緣菲涅耳效果模擬果凍感，沒有真正的折射與次表面散射，質感會比設定圖「塑膠」一些。
2. **體內星空**：用程式繪製的星空貼圖貼在內層殼上並緩慢流動；設定圖是有深度的立體星雲與閃光點，目前只有平面貼圖的效果。
3. **眼睛**：深藍橢圓 + 下方亮藍 + 2 個高光的簡化版；設定圖的眼睛有漸層虹膜與更多層次高光。
4. **嘴巴**：半圓張口 + 舌頭；形狀與設定圖相近但較簡化。
5. **表情**：只實作動作需要的 3 種——一般、生氣（攻擊時加斜眉）、受傷（> <）。設定圖「表情參考」中的開心、好奇、害怕、暈眩、昏睡**尚未實作**。
6. **翅膀**：V1.1 改為水滴鰭狀；設定圖的翅膀邊緣還有細微波浪，尚未做出。
7. **觸角**：漸細的半透明管子；設定圖觸角更細、更透明，根部與身體融合得更自然。
8. **死亡**：設定圖是攤成水窪、冒出藍色星光火焰；目前是攤平淡出 + 星光粒子爆散，沒有火焰狀星光。
9. **重生**：設定圖是光環中先出現帶星星的小水滴；目前是光環 + 上升星光 + 星星先出現，再由小變大回彈成形，**粒子是往上飄，不是往中心聚合**，也沒有獨立的「小水滴」階段。
10. **觸角方向**：首次渲染發現觸角彎向與設定圖正面圖左右相反（尚未修正，待確認）。
11. **尺寸**：遊戲內暫定身高 0.8 公尺（模型參數，可調）。

### 仍未達設定圖品質（需 Blender / GLB 或手繪貼圖）

- 身體、翅膀、觸角之間沒有真正的有機融合（目前是獨立網格疊合，根部以小鼓包遮接縫）。
- 翅膀邊緣沒有設定圖的波浪狀切口與羽狀紋理。
- 體內星雲是程式產生的漸層＋星點，層次與色彩豐富度不及手繪。
- 表情是貼圖切換，沒有 morph target 的漸變（例如眨眼、嘴型過渡）。
- 沒有真正的螢幕空間折射（看不到身體後方景物的扭曲），僅以 refract() 估算體內路徑長來調色。
- 高光為世界空間固定方向，鏡頭轉到背面時高光位置會跟著光源而非畫面固定。

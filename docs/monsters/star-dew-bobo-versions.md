## 決策紀錄（2026-11-19，使用者確認）
- 造型以設定圖三視圖為準；材質、反射、透明、發光以主視覺大圖為準
- 頭頂星星可依設定圖調整大小與厚度（V3.8），保持檸檬金黃與晶瑩質感，不改觸角比例
- 眼睛、嘴巴、腮紅可依設定圖重畫（V3.9），保留 8 種表情與切換功能
- 腹部星星暫時維持 0.0714；材質改善後仍有明顯差異再提出比例建議
- 人工美術貼圖列為後續品質提升方案；先用烘焙貼圖、邊緣反射、內部光感、低成本透明材質
- 驗收目標（3 隻、高畫質、2x）：平均 ≥58、最慢 1% ≥45、Draw Calls ≤25

## 回退方式
每一版的分支與預覽網址都保留；要回到某一版，直接使用該版分支與網址。測試頁可用 `?lab=bobo35`、`?lab=bobo36` 等切換版本對照。

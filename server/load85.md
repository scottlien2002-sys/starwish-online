# Stage 8.5 多人效能測試（伺服器數據）

> CI／本機伺服器數據，不是 iPhone 實機結果（iPhone 畫面效能由實機測試填寫）

環境：Node v22.23.5、AMD EPYC 9V45 96-Core Processor（4 核）、15.6 GB（GitHub Actions）；每個情境 20 秒；20% 機器人加 120±40 ms 延遲；每 2 秒一位斷線重連；一條連線持續送格式錯誤封包。

# 初心者 V2：設定圖量測（Stage 5.4 V2 步驟 A）

- `measure.py`：從男女初心者設定圖量測輪廓、部位比例（設定圖不放進儲存庫，執行時傳入路徑）
  - `python3 art/novice-v2/measure.py <男.png> <女.png> <輸出資料夾> --report`
  - 輸出 `measurements.json`（比例與標註點）、`annot_male.png`、`annot_female.png`（設定圖標註，不提交）
- `measurements.json`：本次量測結果（只有數字）
- 報告：專案文件 Starwish_Stage5_4_V2_StepA_Measurements
